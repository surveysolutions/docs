**.NET 10 support**

Survey Solutions now fully supports .NET 10. Servers can be installed and run
on the latest supported .NET platform while retaining the existing Survey
Solutions functionality.

**Web interview settings copy on the next questionnaire version import**

When a new questionnaire version is imported, its web interview settings are
now copied from the preceding version. This preserves the configuration of web
interviews between questionnaire versions and avoids having to reconfigure the
settings after each import. See [Web interviewing](/headquarters/cawi/web-interviewing/)
for more information.

**Use DEFAULT LANGUAGE as default selection for Translation on Export page**

The Translation on Export page now selects `DEFAULT LANGUAGE` by default. This
makes the standard questionnaire language immediately available for export,
while users can still choose another language when needed.
